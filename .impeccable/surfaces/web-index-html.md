# Cocktailkarte · Operate

Audience: friends checking a real bar menu on phones, sometimes offline or in dim light. Task: locate a drink, read prior opinions directly beside it, add a rating quickly. Real content: the Fuego menu and authenticated group ratings; no invented reviews or imagery.

## Direction contract

THESIS: The menu is the shared object; each friend's rating becomes a readable margin note beside the relevant drink.

OWN-WORLD: A restrained bar notebook on light, neutral paper with no dark frame. Plum ink marks actions, one muted blue tint marks shared notes, and fine rules with a single binding edge provide a few notebook details. Typography stays clear and familiar, with italic note text as the only personal voice.

STORY: Open the menu, find a cocktail, see what the group thought, then add one's own take. Search and ingredient filters still work; a notes filter reveals annotated drinks quickly.

FIRST VIEWPORT: Compact brand and connection status above a clear title. Search and filters stay above the first paper menu sheet. Each drink carries its printed name, ingredients and price; existing opinions appear immediately below as short attributed notes. The rating action remains on the drink row.
